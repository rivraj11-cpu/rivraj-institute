# Rivraj Institute Shikohabad - Production Web Application

Built with:
- Next.js 15
- TypeScript
- Tailwind CSS
- Framer Motion & Lucide Icons
- Supabase Database & Auth Ready
- Cloudinary Media Ready
- Netlify Deployment Ready

## Quick Start
1. Run `npm install`
2. Configure `.env.local` based on `.env.example`
3. Run `npm run dev` to start local development server at `http://localhost:3000`
4. Run `npm run build` to verify production build.
